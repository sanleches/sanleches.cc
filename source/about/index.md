I'm Santiago Ugarte, a software developer based in Ottawa and currently at Kinaxis. My background includes computer engineering technology, computer science, and mechatronics.

I am most interested in software that meets the physical world: modern C++ and C, Linux systems, embedded devices, hardware interfaces, Qt applications, and reliable CMake-based development workflows. I also use this site to document what I learn across the broader software stack.

## Selected projects

- [RadioHijackCpp](https://github.com/sanleches/RadioHijackCpp) controls an RDA5807M FM receiver with a Raspberry Pi Pico 2 W and exposes a local API and web interface.
- [cpp_qt_blank](https://github.com/sanleches/cpp_qt_blank) is a ready-to-build Qt 6 application template with build, test, dependency-check, and VS Code tooling.
- [Cpp11PracticeCheatsheet](https://github.com/sanleches/Cpp11PracticeCheatsheet) collects focused C++ examples for documentation-assisted practice.
- [CMakeTemplate](https://github.com/sanleches/CMakeTemplate) is a compact starting point for modern C++ projects using CMake.
