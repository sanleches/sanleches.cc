I'm Santiago Ugarte, a software developer based in Ottawa and currently at Kinaxis. My background includes computer engineering technology, computer science, and mechatronics.

I am most interested in software that meets the physical world: modern C++ and C, Linux systems, embedded devices, hardware interfaces, Qt applications, and reliable CMake-based development workflows. I also build .NET applications and practical AI systems using document ingestion, RAG, vector search, and language models.

## Selected projects

- [RadioHijackCpp](https://github.com/sanleches/RadioHijackCpp) controls an RDA5807M FM receiver with a Raspberry Pi Pico 2 W and exposes a local API and web interface.
- [Ish](https://github.com/sanleches/Ish) is a hand-written compiler front end in C with a scanner, recursive-descent parser, AST, and symbol table.
- [Parking Garage of the Future](https://github.com/sanleches/PGOF) is a C++17 simulation of space allocation, waiting queues, parking duration, and fees.
- [GNOME Wallpaper Randomizer](https://github.com/sanleches/gnome-wallpaper-randomizer) is a small Bash utility that picks a wallpaper at login without running a daemon.
- [Linux Driver Introduction](https://github.com/sanleches/linux_driver_introduction) is a set of focused kernel-module exercises covering lifecycle callbacks, logs, character devices, VFS operations, and USB discovery.
- [FluKsAI](https://ironcladapp.com/resources/articles/winners-legal-ai-innovators-award-2025) is an award-winning internal contract RAG application for semantic search and natural-language review across a large contract repository.

You can find the rest of my work on [GitHub](https://github.com/sanleches) and my professional history on [LinkedIn](https://www.linkedin.com/in/santiago-ugarte-419200152).
